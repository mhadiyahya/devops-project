# DAY 01 - Project Foundation and Local Container Deployment
Author: Muhammad Hadi Yahya
Date: 26/08/2026
Remark: DevOps Project for Infratify

## Objective
The objective of Day 1 is to establish the basic foundations ofr the DevOps project.

## Initial scope:
* Create the project structure.
* Initialize Git source control.
* Create a minimal application.
* Containerize the application using Docker.
* Deploy the application using Docker Compose.
* Test the application and health endpoint.
* Prepare the project for the future CI/CD and infrastructure automation.
